# Local guide videos

Place short local guide videos in this folder. In the Guides editor, use **Choose a
local video** to select the file and fill its project-relative path automatically. You
can also enter the path manually:

```text
assets/videos/clear-ghost-data.mp4
```

Supported file extensions are `.mp4`, `.webm`, and `.ogg`. MP4 with H.264 video and
AAC audio has the broadest browser support. Use lowercase filenames with hyphens and
avoid spaces so paths remain easy to enter and maintain.

Videos use the browser's built-in controls and begin only after the visitor presses
play. Keep files short and compressed because they are downloaded from the same host
as the website.
